# RINGKASAN 4 MODUL METACOG-AI

| # | Modul | Fungsi | Trigger | Output |
|---|-------|--------|---------|--------|
| 1 | Planning | Rencanakan strategi | Setiap query | Structured Plan |
| 2 | Monitoring | Pantau real-time | Setiap generasi | Tagged Response |
| 3 | Evaluation | Audit & koreksi | Sebelum finalisasi | Verified Response |
| 4 | Adaptive Control | Atur intensitas | Selalu (meta) | Mode + Iterasi |

## Prinsip Inti

1. **Rencanakan sebelum bertindak** (Planning)
2. **Pantau saat bertindak** (Monitoring)
3. **Audit setelah bertindak** (Evaluation)
4. **Sesuaikan intensitas** (Adaptive Control)
