# METACOG-AI
## Metacognitive Self-Regulation & Reliability Enhancement System

> **Versi:** 1.0.0
> **Tipe:** AI Enhancement Skill
> **Basis Riset:** Ann Brown Metacognition Cycle, NeurIPS 2025, IEEE 2025

---

## 🎯 Tujuan

METACOG-AI adalah skill yang dirancang untuk **memperkuat model AI** dengan
mengatasi 6 kekurangan fundamental:

1. Halusinasi & overconfidence
2. Penalaran kaku (inflexible reasoning)
3. Sindrom "Yes-Man" (sycophancy)
4. Kegagalan regulasi diri
5. Respons buruk terhadap kontradiksi
6. Dinding penskalaan (scaling wall)

---

## 🏗️ Arsitektur

Skill ini mengoperasionalkan **siklus regulasi Ann Brown**:
Planning → Monitoring → Evaluation → Adaptive Control

---

## 🚀 Quick Start

1. Baca `00_OVERVIEW.md` untuk memahami dasar teori
2. Pelajari 4 modul di folder `01_core/`
3. Copy prompt dari folder `02_prompts/`
4. Lihat contoh di `03_examples/`
5. Integrasikan via `05_integration/`
